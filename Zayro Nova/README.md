# ZAYRO NØVA

**FINE ATTIRE COLLECTION**

Proyecto de desarrollo de una aplicación para la gestión de ventas e inventario de ZAYRO NØVA.

## Objetivo
Desarrollar una aplicación con Python y Flet para administrar productos, registrar ventas y controlar el inventario de la marca.

## Tecnologías
- Python
- Flet
- SQLite3
- GitHub Actions para automatizar la compilación de Android

## Funcionalidades previstas
- Registro y consulta de productos.
- Control de existencias.
- Registro de ventas.
- Almacenamiento local de datos.
- Preparación para Android mediante APK.

## Compilación
La compilación para Android se configurará mediante GitHub Actions.
